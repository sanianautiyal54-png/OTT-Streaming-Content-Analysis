OTT Streaming Content Trend Analysis — Netflix

Project Overview

This project analyzes Netflix's content catalog to identify trends in content types, genres, countries, content ratings, yearly additions, and movie durations.

Objectives

- Analyze the distribution of movies and TV shows.
- Explore content additions over time.
- Identify the most frequently listed genres and countries.
- Examine content ratings and movie durations.
- Develop actionable business recommendations.

Dataset

Netflix Movies and TV Shows dataset containing 8,807 titles and 12 original columns.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL Server Management Studio (SSMS)
- SQL Server

Project Workflow

1. Data inspection and cleaning
2. Exploratory Data Analysis (EDA)
3. Six data visualizations
4. SQL queries and aggregations
5. Business recommendations
6. Conclusion and limitations

Key Findings

- Movies: 6,131
- TV Shows: 2,676
- Average movie duration: approximately 99.58 minutes
- The United States has the highest country representation in the dataset.

Business Recommendations

1. Evaluate opportunities to diversify content types.
2. Explore regional content opportunities.
3. Use genre and runtime trends to guide content planning.

Limitations

The dataset describes the content catalog and does not provide actual viewership, subscriber engagement, or revenue data.
